States, in order

Sidebar uses three states. Disabled is rare — prefer hiding the item entirely.

  • Default — color: var(--fg2), icon --fg3.
  • Hover — fill --bg-muted, text --fg1, icon --fg2.
  • Active — fill --brand-soft, text + icon --brand-active, 3 px left accent.

Group labels are uppercase eyebrows (10.5 px, .1em letter-spacing, --fg4) — never decorated, never collapsible by default.

Counts sit right-aligned in the row, in --accent (orange-500) on white. Use them only when the count is actionable (3 anomalies, 12 unread events).
